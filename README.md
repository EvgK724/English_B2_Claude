# Английский B2

60 тренажёров английского B1–B2 в одном приложении для iPhone и iPad: каталог по группам,
«Сегодня к повторению», поиск, карточки с интервальным повторением, озвучка голосом Microsoft Ryan
(в «Фразах из Breaking Bad» сохранён Andrew). Оформление — как у want-you-to из репозитория test01.
Ежедневное пополнение GitHub-версии перенесено на Codex: один фразовый глагол и две фразы из Breaking Bad.
Codex готовит проверенные тексты в JSON; существующий GitHub Actions создаёт записи Ryan/Andrew
и публикует карточки только после проверки всей озвучки. Неподготовленная очередь в приложение не попадает.
Расписания настраиваются отдельно; старые артефакты на claude.ai этим процессом не обновляются.

Ссылка (GitHub Pages): https://evgk724.github.io/English_B2_Claude/site/

## Как поставить на экран «Домой»

1. Откройте ссылку в **Safari** на iPhone или iPad.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран „Домой“» → «Добавить».

Приложение откроется во весь экран со своей иконкой. Без интернета открываются все темы; звук — в темах,
которые уже открывали хотя бы раз (все записи вместе — около 90 МБ, поэтому они не скачиваются заранее).

## Как слушать слова и фразы

1. Откройте приложение с интернетом, чтобы загрузились новые записи.
2. Выберите раздел и нажмите значок динамика рядом со словом или примером.
3. Для автоматического чтения карточек включите звук в самом тренажёре.

В 59 разделах звучит **Microsoft Ryan (en-GB-RyanNeural)**; «Breaking Bad» — **Andrew (en-US-AndrewNeural)**.
Если открыта старая версия, закройте приложение и откройте его снова с интернетом.
Загруженные записи сохраняются для повторения без сети. Прогресс при обновлении сохраняется.

Новые слова, примеры и фразы озвучиваются Ryan автоматически при обновлении приложения на GitHub.
Отдельно просить об озвучке не нужно: публикация проходит после создания и проверки всех новых записей.
При исправлении английского текста запись Ryan обновляется. Для «Breaking Bad» действует отдельная
проверка Andrew; Ryan этот раздел не обрабатывает. Неожиданное изменение старой записи требует проверки.
Если сервис озвучки временно недоступен, остаётся предыдущая опубликованная версия, а проверка повторяется
по часовому расписанию. После успешной публикации откройте приложение с интернетом.

Состояние обновления: [Ryan audio and Pages](https://github.com/EvgK724/English_B2_Claude/actions/workflows/ryan-pages.yml).

## Прогресс на двух устройствах

Прогресс хранится на самом устройстве. Чтобы продолжить на другом: внизу главного экрана
**«Сохранить прогресс»** → AirDrop на iPad (или «Сохранить в Файлы») → на iPad **«Загрузить прогресс»** и выбрать
файл `english-progress-….json`. Карточки сливаются по времени ответа: более свежий ответ побеждает, ничего не теряется.

В версии на claude.ai (https://claude.ai/artifact/15er8g7yJZJ5tCpvRXK3ZM) прогресс синхронизируется сам.

## Запуск на компьютере

В `site/` хранится исходный сайт, согласованный с историей дневных запросов и журналов.
Исправления русских переводов добавляются отдельными записями в `data/corrections/`;
прежние запросы, журналы и записи исправлений не переписываются. При сборке публикации
они применяются к временной копии сайта, а каталог и офлайн-кэш пересобираются.
Английские тексты, аудио, идентификаторы карточек и прогресс сохраняются.

Чтобы открыть ту же версию, которая публикуется в Pages, соберите её вне репозитория:

```
python3 tools/build_publication.py build --output /tmp/english-b2-preview
python3 -m http.server 8000 --directory /tmp/english-b2-preview
```

и открыть http://localhost:8000/site/.

Инструкции по сопровождению проекта и учебный профиль хранятся отдельно от публичных файлов приложения.
