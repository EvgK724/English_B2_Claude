Used to

Четыре похожие конструкции — четыре разных смысла: used to — раньше, be used to — привык, get used to — привыкаю, would — так бывало.

Что с чем

used to+ глаголI used to smoke.раньше курил, теперь нет
would+ глаголWe would go fishing.так бывало — только действия
be used to+ -ing или сущ.I'm used to working nights.привык, мне привычно
get used to+ -ing или сущ.You'll get used to it.привыкаешь, привыкнешь

Как выбрать

  1. 1

    Раньше было, а теперь нет?

    used to + глагол · и действия, и состояния

  2. 2

    Так бывало, повторялось в рассказе?

    would + глагол · только действия

  3. 3

    Уже привычно, «привык»?

    be used to + -ing или сущ.

  4. 4

    Привыкаешь, это процесс?

    get used to + -ing или сущ.

Перед used to стоит be или get — дальше -ing. Нет — обычный глагол.

Отрицание и вопрос — без d: didn't use to, Did you use to…? «Обычно» в настоящем — usually, а не use to.

Одна ситуация — разный смысл

I used to work nights.

раньше работал по ночам, теперь нет

I'm used to working nights.

привык работать по ночам

I'm getting used to working nights.

привыкаю работать по ночам

She used to live in Moscow.

жила — это состояние, только used to

Every Sunday she would visit her mother.

навещала — действие, можно would

I used to smoke.

раньше курил

Did you use to smoke?

в вопросе — use без d

I didn't use to smoke.

в отрицании — тоже без d

You'll get used to it.

привыкнешь — процесс

I'm used to it.

привык — уже привычно

She's used to reading MRI scans.

привыкла читать МРТ

MRI is used to detect small infarcts.

МРТ используют, чтобы выявлять мелкие инфаркты

Частые ошибки

  • Неверно: I'm used to work at night. → верно: I'm used to working at night.после be used to — -ing
  • Неверно: I used to working nights. → верно: I used to work nights.раньше делал — used to + глагол
  • Неверно: I didn't used to smoke. → верно: I didn't use to smoke.после did — use без d
  • Неверно: I was used to smoke. → верно: I used to smoke.«раньше курил» — без was
  • Неверно: I would live in Moscow. → верно: I used to live in Moscow.состояние — только used to
  • Неверно: She would have long hair. → верно: She used to have long hair.have — состояние, только used to
  • Неверно: There would be a cinema here. → верно: There used to be a cinema here.«раньше был» — there used to be
  • Неверно: I use to get up at six. → верно: I usually get up at six.сейчас обычно — usually
  • Неверно: I can't get used to live here. → верно: I can't get used to living here.после get used to — -ing
  • Неверно: You will used to it. → верно: You'll get used to it.привыкнешь — get used to
